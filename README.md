# Python Multi-Tool 

A command-line Python toolkit that combines several small utilities and games into one application.

## Features

###  Calculator
- Addition
- Subtraction
- Multiplication
- Division
- Modulo
- Floor division
- Power

###  BMI Calculator
Calculates BMI based on weight and height and displays the BMI category.

###  Unit Converter
- Length conversion
- Weight conversion
- Area conversion

###  Temperature Converter
- Celsius ↔ Fahrenheit
- Celsius ↔ Kelvin

###  Age Calculator
- Gregorian birthday
- Persian (Jalali) birthday
- Calculates age in years, months, and days
- Displays Gregorian and Persian dates
- Calculates the approximate time until the next birthday

###  Password Generator
Generate passwords using:
- Letters
- Numbers
- Symbols
- Different combinations of characters

The generator can create passwords without repeating characters.

### 🎮 Rock Paper Scissors
Two game modes:
- Play against the computer
- Play with two human players

The game uses a first-to-3 scoring system.

## Technologies
